Текущий переключаемый закупочный набор: dataset.zip

Архив должен содержать 4 пары файлов:
- Предзащита_Извещения_1.csv + Предзащита_Потоварка_1.csv
- Предзащита_Извещения_2.csv + Предзащита_Потоварка_2.csv
- Предзащита_Извещения_3.csv + Предзащита_Потоварка_3.csv
- Предзащита_Извещения_4.csv + Предзащита_Потоварка_4.csv

Переключение выполняется из админки. При выборе набора заменяются только
импортированные закупки; пользовательские заявки, поставщики и их история
не удаляются.

Старый RLT.Uni_СПБ_1-2_10_2026.zip для этих кнопок больше не используется.
