# ML artifacts

Эта папка содержит рабочие артефакты предоставленного пользователем модуля semantic retrieval.

- `suppliers.index` — оригинальный FAISS index из `MODELS_&_SCRIPT(1).rar`.
- `supplier_index_map.csv` — карта строк индекса на ИНН и технические метрики прототипа. Создана из оригинального `data/suppliers_cube.csv` с сохранением исходного порядка строк.
- `index_meta.json` — метаданные интеграции.

Полный `suppliers_cube.csv` (~198 МБ) намеренно не дублируется: runtime нужны только row->ИНН и готовый FAISS index. Реальные статистика, отзывы, контакты, география и история берутся из основной SQLite БД проекта.
